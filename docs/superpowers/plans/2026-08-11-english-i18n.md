# English i18n Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a complete English interface that follows the visitor's browser language and can be switched from the top-right control.

**Architecture:** Keep one canonical HTML document and add a dependency-free client-side translation runtime. The runtime preserves the Chinese source copy, applies curated English card names and descriptions, translates metadata and accessibility labels, and exposes a tiny API for dynamic navigation and counter components.

**Tech Stack:** Static HTML, CSS, vanilla JavaScript, GitHub Pages, existing Cloudflare Worker APIs.
